# V1 Definition

NyxBot v1 is a chat-first, visually expressive persona interface for conversation, roleplay, and image-centered interaction.

Its purpose is to create the first stable body for Nyx:
something usable,
recognizable,
and extensible.

## Core outcomes

V1 should make it possible to:
1. interact with Nyx in a distinct voice
2. switch between conversation mode and roleplay mode
3. shape or generate image ideas through a visual mode
4. maintain lightweight continuity through profile and session memory
5. prepare for future integration into ONE

## V1 scope

Included:
- web chat shell
- mode switcher
- persona prompt structure
- roleplay prompt structure
- visual mode placeholder or first implementation
- profile/memory scaffolding
- integration notes

Not included:
- full autonomy
- long-term memory engine
- full ECKO wiring
- complex agent loops
- complete governance system

## Success condition

V1 succeeds if NyxBot already feels like Nyx,
even before the deeper architecture is complete.
